# 빅데이터 MD 유형 테스트 앱 플로우

Oct 21, 2026 · @Sungmin

## 개요

설명회 참석자가 2분 안에 빅데이터표준 마이크로디그리(MD) 6종 중 자신에게 맞는 1개를 추천받고, 바로 들을 과목까지 확인하는 것이 목표입니다. 시작 화면 다음에 두 갈래로 나뉩니다.

- **흥미 기반으로 알아보기**: 상황형 질문 8개에 답하면 점수가 가장 높은 유형을 추천합니다. 아직 들은 과목이 없는 저학년·비전공자용입니다.
- **과목 기반으로 알아보기**: 이미 들은 과목을 체크하면 MD별 진행률(n/4)을 계산해 가장 빨리 끝낼 수 있는 유형을 추천합니다. 고학년·관련 전공자용입니다.

결과 범위는 시작 화면에 있는 표준 MD 6종(빅데이터초급·관리·분석·머신러닝·마이닝·고급)입니다. 학과를 입력한 경우에만 해당 학과의 연계융합표준 MD를 보조 카드로 덧붙입니다.

설계 원칙

1. 로그인·개인정보 없이 QR로 바로 시작하고, 응답은 기기 안에서만 계산합니다.
2. 과목 인정은 교과목명이 아니라 교과번호로 판정합니다(PDF FAQ Q2). 그래서 과목 칩에는 항상 번호와 개설 학과를 함께 표시합니다.
3. 과목 목록·개설 여부는 코드에 넣지 않고 데이터 파일로 분리합니다. 학기마다 개설 과목만 교체하면 됩니다.
4. 결과는 ‘추천’일 뿐이므로, 최종 인정은 사업단 확인이 필요하다는 문구를 결과 하단에 둡니다.

## 전체 플로우

과목 기반에서 아무것도 고르지 않으면 흥미 기반으로 넘어가고, 결과 화면에서는 언제든 반대쪽 분기로 갈 수 있습니다.

## 화면 흐름

모든 참여자는 시작 → 모드 선택 → 학과 선택(건너뛰기 가능)을 거친 뒤 두 갈래 중 하나로 갈라지고, 같은 결과 화면 틀에서 만납니다.

| 화면 | 주요 요소 | 다음 이동 |
| --- | --- | --- |
| S0 시작 | 첨부 이미지 그대로. 표준 MD 6종 칩, \[테스트 시작하기\] | S1 |
| S1 모드 선택 | 큰 카드 2개. \[흥미 기반으로 알아보기\] “아직 들은 과목이 없거나 적어요 · 8문항 · 약 2분” / \[과목 기반으로 알아보기\] “들은 과목을 체크하면 진행률을 알려줘요”. 아래 보조 문구 “잘 모르겠다면 흥미 기반부터” | S2 (선택한 모드 기억) |
| S2 학과 선택 | “어느 학과인가요?” 드롭다운. 연계융합 MD가 있는 14개 학부·과 + ‘기타/건너뛰기’ | 흥미 → S3, 과목 → S4 |
| S3 흥미 질문 | 1문항 1화면, 상단 진행 바(1/8). 선택지 탭 시 0.3초 뒤 자동 넘김, 뒤로가기 시 응답 유지 | Q8 후 S5 |
| S4 과목 체크 | 검색창 + 슬롯 카드 목록(아래 과목 기반 분기 참고), 하단 고정 \[결과 보기 (n개 선택)\] | 1개 이상 → S5, 0개 → S3 안내 |
| S5 계산 중 | 캐릭터 애니메이션 1.5초, “나에게 맞는 MD를 찾는 중” | S6 |
| S6 결과 | 유형 카드, 추천 로드맵, 함께 따기 좋은 MD, 연계융합 카드, 이수 신청 방법(아래 결과 화면 참고) | S7 또는 반대 분기 |
| S7 마무리 | \[다른 방식으로도 알아보기\] \[다시 하기\] \[결과 이미지 저장\] | S3/S4 또는 S0 |

학과 선택을 공통 단계로 둔 이유는 과목 기반에서 그 학과의 연계융합 지정 과목을 체크 목록에 넣어야 하기 때문입니다. 흥미 기반에서는 결과 화면의 연계융합 카드에만 씁니다.

## 흥미 기반 분기

질문을 두 축으로 나눕니다. Q1–Q2는 **준비도**(0–6점)를 재고, Q3–Q8은 초급을 놨 5개 유형의 **관심 방향** 점수를 쌓습니다. 빅데이터초급은 관심 분야가 아니라 수준의 문제라서, 준비도로만 결정합니다.

준비도 문항 (선택지 A–D = 0–3점)

1. Q1. 지금 나의 데이터·코딩 경험은?
   - A 아직 거의 없어요 · B 교양이나 기초 수업에서 조금 해봤어요 · C 파이썬·R로 직접 데이터를 다럄봤어요 · D 모델을 학습시키거나 데이터 프로젝트를 해봤어요
2. Q2. 수학·통계는 나에게?
   - A 아직 낯설어요, 기초부터 배우고 싶어요 · B 평균·분산 같은 기초 통계는 괜찮아요 · C 확률·회귀 같은 개념도 익숙해요 · D 선형대수·다변량까지 깊게 파고 싶어요

관심 방향 문항 (화살표 뒤가 가산점)

1. Q3. 축제에서 우리 과 부스를 맡았다. 데이터로 뭘 해볼까?
   - A 어떤 메뉴·시간대가 매출을 올렸는지 분석 → 분석 +2
   - B 내일 방문자 수를 예측하는 모델 만들기 → 머신러닝 +2
   - C SNS 후기와 사진으로 사람들 반응 살펴보기 → 마이닝 +2
   - D 주문·재고 데이터를 한곳에 모아 관리하기 → 관리 +2
2. Q4. 가장 끌리는 데이터는?
   - A 숫자가 빼곡한 표 → 분석 +1, 머신러닝 +1
   - B 리뷰·대화 같은 글 → 마이닝 +2, 고급 +1
   - C 사진·영상 → 마이닝 +2, 고급 +1
   - D 끝없이 쌓이는 로그·센서 기록 → 관리 +2, 고급 +1
3. Q5. 팀 프로젝트에서 맡고 싶은 역할은?
   - A 데이터 구조를 설계하고 DB 세팅하기 → 관리 +2
   - B 결과를 그래프로 보여주고 해석하기 → 분석 +2
   - C 모델 정확도 끌어올리기 → 머신러닝 +2
   - D 최신 기술(LLM·클라우드) 붙여보기 → 고급 +2
4. Q6. 가장 클릭하고 싶은 기사 제목은?
   - A “집값을 움직인 진짜 요인, 데이터로 밝혔다” → 분석 +2
   - B “AI가 다음 달 수요를 맞혔다” → 머신러닝 +2
   - C “챗봇은 어떻게 문장을 이해할까” → 마이닝 +2
   - D “하루 수억 건을 처리하는 시스템의 비밀” → 고급 +2, 관리 +1
5. Q7. 문제를 풀 때 나는?
   - A 전체 구조와 설계도부터 그린다 → 관리 +2
   - B 숫자 뒤에 숨은 원인을 끝까지 따진다 → 분석 +1, 머신러닝 +1
   - C 일단 만들어 돌려보고 고쳐 나간다 → 머신러닝 +1, 마이닝 +1
   - D 원리를 수식 수준까지 이해해야 직성이 풀린다 → 고급 +2
6. Q8. 5년 뒤 내 모습에 가장 가까운 것은?
   - A 데이터 분석가·리서처 → 분석 +2
   - B AI·머신러닝 엔지니어 → 머신러닝 +2
   - C 자연어·컴퓨터비전 AI 개발자 → 마이닝 +2, 고급 +1
   - D 데이터 엔지니어 → 관리 +2, 고급 +1

결과 산출 규칙

1. 준비도 = Q1 + Q2. 0–1은 입문, 2–4는 성장, 5–6은 심화 단계입니다.
2. 관심 점수 = Q3–Q8 가산점 합계. 심화 단계면 고급에 +2를 더합니다.
3. 관심 1위가 동점이면 Q8(커리어)이 가리키는 유형 → Q5(역할)가 가리키는 유형 → 고정 순서(머신러닝 > 분석 > 마이닝 > 고급 > 관리, 교내 개설 과목이 많은 순) 순으로 고릅니다. Q8 D는 관리, Q5 D는 고급을 가리킵니다.
4. 입문 단계 → 주 결과는 빅데이터초급, 관심 1위는 ‘다음 목표 MD’로 함께 보여줍니다. 그 외 → 주 결과는 관심 1위 유형입니다.

응답 조합 65,536개(4⁸)를 전수 계산하면 6개 유형이 각각 15.0–18.8%로 고르게 나옵니다. 각 유형의 전형적인 응답(예: Q3–Q8에서 관리 선택지만 고름)은 모두 의도한 유형으로 나오며, 동점은 약 23%에서 생겨 대부분 Q8로 갈립니다. 문항이나 가산점을 바꾸면 이 분포를 다시 확인해야 합니다.

## 과목 기반 분기

체크한 과목을 MD별 ‘슬롯’에 맞춰 진행률(n/4)을 계산하고, 진행률이 가장 높은 MD를 추천합니다. 슬롯은 ‘본 과목 + 대체 과목 + 구 교과번호’를 한 묶음으로 본 단위입니다(데이터 테이블 참고).

체크 화면(S4) 구성

- 상단 검색창: 과목명이나 교과번호로 필터.
- 슬롯 카드 20개를 3개 묶음으로 표시: 기초(통계·프로그래밍) / 데이터 관리·분석 / AI·고급. 카드 안 칩은 “경영통계학 27003 · 경영학부”처럼 번호와 학과를 함께 보여줍니다.
- 대체 과목은 본 과목 칩 아래 ‘이 과목도 인정돼요’로 펼쳐 보여줍니다. 통계 슬롯은 대체 과목이 11개라 기본으로 펼친 상태가 좋습니다.
- 구 교과번호 칩: 빅데이터개론2 01914, 빅데이터와통계읽기 47783을 ‘(구)’ 표시로 넣고 새 번호와 같은 슬롯에 묶습니다.
- 학과를 선택했다면 맨 위에 ‘내 학과 연계 과목’ 묶음을 추가합니다.
- 맨 아래 접힌 영역 ‘타 대학 학점교류로 들은 과목’: 교내 미개설 6개(인공지능입문 등).

계산 규칙

1. 충족 슬롯 수: 체크한 번호가 슬롯의 번호 중 하나와 일치하면 충족. 같은 슬롯 과목을 여러 개 들어도 1개로 셈니다(예: 경제통계학 + 경영통계학 = 통계 슬롯 1개).
2. 진행률 = min(충족 슬롯, 4) / 4. MD 6개 모두 계산합니다. 슬롯은 MD 간 공유되므로(딕러닝은 분석·머신러닝·마이닝 공통), 한 과목이 여러 MD에 동시에 반영됩니다(PDF p.24 중복 인정).
3. 추천 MD = 진행률 1위. 동점이면 남은 슬롯 중 이번 학기 개설 과목이 많은 MD → 고정 순서(흥미 기반과 동일).
4. 남은 과목 추천: 남은 슬롯을 ① 이번 학기 개설 ② 교내 개설(이번 학기 아님) ③ 학점교류 순으로 정렬해 부족한 개수만큼 보여줍니다. 같은 순위 안에서는 다른 MD와 많이 공유되는 슬롯을 먼저 둡니다.
5. 4/4를 채운 MD가 있으면 추천 대신 ‘이미 요건 충족! 인증 신청하세요’ 카드를 맨 위에 둡니다.
6. 함께 따기: 추천 MD와 다른 MD 5개를 각각 짝지어, 둘 다 4/4가 되려면 더 들어야 하는 최소 과목 수를 구하고 가장 적은 짝을 보여줍니다. 교내 슬롯이 20개뿐이라 전수 탐색으로 충분합니다.

들은 과목이 0개일 때의 최소 과목 수는 이렇습니다. 분석+머신러닝은 통계계산·회귀분석Ⅰ·빅데이터윤리·딕러닝 4과목으로 둘 다 충족합니다. 관리+분석과 마이닝+고급은 5과목, 초급은 다른 MD와 겹치는 과목이 없어 어떤 짝이든 8과목입니다.

연계융합 MD(학과 선택 시)는 별도로 계산합니다. 빅데이터개론 02098(또는 구 01914) 필수 + 학과 지정 과목 2개 + PDF p.21 빅데이터전공 교과목 1개를 각각 체크하며, 빅데이터개론Ⅰ 01919는 필수로 인정하지 않습니다.

## 결과 화면

두 분기가 같은 결과 틀을 씁니다. 다른 점은 2번 구역뿐입니다.

1. 유형 카드: 페르소나 이름 + MD 이름 + 한 줄 설명 + 캐릭터 이미지. 입문 단계면 “다음 목표: ○○” 배지를 함께 둡니다.
2. 근거 막대: 흥미 기반은 관심 점수 5개, 과목 기반은 MD 6개의 진행률(n/4).
3. 추천 수강 로드맵: 4개 슬롯 체크리스트. 이미 들은 과목은 ✓, 남은 과목에는 ‘이번 학기 개설’ 또는 ‘학점교류’ 배지.
4. 함께 따기 좋은 MD: “여기에 n과목만 더하면 ○○까지” 문구와 추가 과목명. 증명서에는 2개 과정까지 기재된다는 안내를 붙입니다.
5. 내 학과 연계융합 MD(학과 선택 시): MD 이름, 지정 과목, 필수 빅데이터개론 02098. 타과 전공은 일반선택으로 인정될 수 있다는 주의 문구.
6. 이수 신청 방법: 대학행정 > 학적 > 모듈형교육과정이수(포기) 신청 > \[이수신청\]. 졸업 전 인증 신청이 필수라는 문구.
7. 하단 안내: “추천 결과이며 최종 인정은 교과번호 기준으로 사업단이 확인합니다 · 문의 02-6490-6926\~6927”.

| MD | 페르소나 | 한 줄 설명 | 대표 추천 4과목 | 함께 따기 좋은 MD |
